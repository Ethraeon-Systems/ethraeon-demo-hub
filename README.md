# ETHRAEON Demo Hub

Public demo aggregation hub for ETHRAEON non-IP experiences and integration previews.

> Humanitas ante Machinam. Humanity before the machine.

ETHRAEON Systems builds a constitutional runtime and evidence control layer for governed AI, ordered Governance, then Execution, then Intelligence. This repository is the public demo face of that platform: cleared, non-IP demonstration frontends, reference integrations, and showcase assets. It is not a chatbot or a model wrapper, and it does not contain protected runtime internals.

## Scope

- Public demo frontends and backend adapters
- Reference integrations for web and API consumption
- Public-safe showcase assets only

What is present is real. What is not yet here is named as scope, never implied as shipped.

## Boundary

This repository excludes protected constitutional runtime internals, private operational evidence, and restricted patent-claim implementations by design.
